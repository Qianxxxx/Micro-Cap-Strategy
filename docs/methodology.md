# 研报口径与实现

## 第 3 节 微盘组合

- 以收盘总市值从小到大排序，平局按股票代码排序。根据历史 ST 和涨停状态判定资格。首次观测到非涨停后视为开板，已退市日期之后剔除。
- T 日收盘确定的最小400和第401–800只分组，从下一交易日开始贡献收益。复权价使用最近生效的后复权因子。缺少相邻交易日行情时，模拟组合当日按零收益记账，覆盖率另列。这可能低估停牌复牌跳跃和实际退市损失。
- 独立退市风险警示、停复牌历史暂缺，分阶段风险以本地合成全 A 等权作为代理。行业是固定快照，行业扩散存在前视风险。
- 对照研报时先看指数日收益相关性和跟踪误差，再查成分与异常交易日。研报第 3 节延伸到 2026-07-24，本工程截止 2026-04-30。

## 第 4 节 市场宽度和资金流

| 指标 | 落地方式 |
|---|---|
| MA20 趋势宽度 | 非 ST 且上市超过180自然日的样本中，复权收盘价高于近20条行情均值的比例 |
| 权重扩散 | 本地全 A 日等权复合20日收益减沪深300全收益指数20日收益 |
| 行业扩散 | 申万一级行业内先按日等权，再计算20日复合收益，统计正收益行业占比 |
| 微盘净买入总量强度 | 月度微盘组合的5日主动净买入额之和除以5日成交额之和 |
| 相对主动强度20日变化 | 当日微盘与沪深300成分组强度差，减去此前20个交易日该差值的均值，至少10个有效观测 |

资金流用上月最后交易日成分作为本月微盘篮子，对照组用沪深300逐日成分。周度敏感性实验以有交易的自然周为单位，用上一有交易周最后一个交易日的收盘名单作为本周篮子。遇到整周休市时沿用最近一个有交易周的收盘名单。该开关只影响资金流指标的微盘篮子。主动净额从千元换算为元，分子分母按双方都有数据的个股匹配，每天保留覆盖率。两个资金指标做 EMA10 平滑。宽度三项与资金两项在组内等权，再对两组等权。

过去五年分位数以当前日前的历史样本为基准。资金流分位数沿用五年，预热期至少252个有效观测，同值计半权。这些是实现设定。沪深300使用本地全收益指数，全 A 及行业等权由本地有有效相邻收益的个股构建。分位数等于50%或缺失时延续前一信号。

## 轮动回测

首日净值设为1，初始持有沪深300。T 日收盘得分，T+1 收盘按得分换仓并扣费，T+2 的区间收益使用新仓位。完全切换的双边名义换手为200%，按单边10 bp 计费。50/50 基准按研报的每日等权资产收益序列实现。相对净值以策略净值除以基准净值，收益年化用自然日区间，波动按252个交易日年化。


## 收益分解

调仓频率对照使用季末、月末、周末和每日收盘的成分。每组比较低频等权、高频换样但保留留存个股权重、高频等权三个组合。中间组合在低频再平衡日重置为等权，其他换样日把卖出所得等分给新成分。两段收益差按逐日对数收益年化，可加总为总频率贡献。中间组合的交易细节按上述实现约定。

彩票效应统计使用月末入组且有次月末价格的个股，分别报告微盘400与相邻组的偏度、P99和收益阈值占比。该统计受月末价格覆盖约束。现有数据未包含中证800逐日成分，研报中的中证800对照尚未覆盖。


## 第 4.4 节 黄金配置

使用 AU9999.SGE 收盘价，按权益回测日期逐日一对一匹配。缺失、重复或无效价格直接报错，期初净值为1。权重取10%、20%、25%、30%、40%和50%，可通过研究配置调整。

每日将黄金与权益恢复到目标比例。策略的权益部分沿用扣除换仓费用后的双维度轮动收益，基准的权益部分使用50/50每日再平衡收益。黄金及跨资产再平衡未另计交易成本。相对收益按同黄金权重的策略与基准净值之比计算，2026年只统计到4月30日。
